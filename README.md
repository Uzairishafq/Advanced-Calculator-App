# Advanced Calculator App

An Android calculator application developed using **Python and Kivy** as a college project.

## Features

- Basic arithmetic operations
- Scientific calculator functions
- Calculation history
- Dark and Light themes
- Custom app icon
- Android APK support

## Technologies Used

- Python
- Kivy
- Buildozer
- Android SDK

## About the Project

This project was assigned by my college. I developed the application with some assistance from AI tools for guidance, problem-solving, and improving the development process.

## Learning Outcomes

- Improved Python programming skills
- Learned Kivy application development
- Gained experience in Android APK building
- Practiced problem-solving and debugging
